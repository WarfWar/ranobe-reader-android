# Ranobe Reader for Android

Android-приложение для чтения и перевода ранобэ с https://mtlnovel.me/.

Проект разрабатывается на Kotlin с Jetpack Compose. Автоматическая сборка APK — GitHub Actions.

Первая версия: открытие ссылки на главу, извлечение текста, перевод EN → RU с ML Kit, навигация по главам.
