# Ranobe Reader for Android

Прототип Android-приложения для чтения глав с [mtlnovel.me](https://mtlnovel.me/) и перевода их с английского на русский.

## Реализовано

- Открытие сайта во встроенном браузере для поиска произведений и глав.
- Загрузка текста страницы главы по HTTPS и извлечение основного текста с помощью Jsoup.
- Читалка с настройкой размера шрифта и кнопками предыдущей/следующей главы (если ссылки обнаружены).
- Машинный перевод EN → RU с помощью **Google ML Kit** прямо на устройстве.
- Автоматическая сборка **debug APK** при отправке изменений в ветку main через GitHub Actions.

## Как получить APK

1. Перейдите на вкладку [Actions](https://github.com/WarfWar/ranobe-reader-android/actions).
2. Откройте workflow **Android APK**.
3. Выберите успешный запуск (зелёная галочка).
4. Внизу страницы в разделе **Artifacts** скачайте **ranobe-reader-debug-apk**.
5. Распакуйте ZIP и установите **app-debug.apk** на Android.

Пока сборка не завершилась успешно, APK может отсутствовать. Для первой ручной сборки доступен пункт **Run workflow**.

## Локальная сборка

Требования: Android Studio, JDK 17, Android SDK 35 и Gradle 8.11.1.

Откройте репозиторий в Android Studio как Gradle-проект и соберите вариант **debug**. Альтернативно при установленном Gradle 8.11.1:

`gradle :app:assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Использование

- Нажмите **Открыть сайт**, найдите нужную главу и выберите **Читать открытую страницу**. Либо вставьте прямую HTTPS-ссылку на главу в поле и нажмите **Читать**.
- Когда текст загрузится, нажмите **Перевести**. При первом запуске перевода устройство скачает языковую модель; потребуется интернет.
- Для русского перевода используется локальная модель ML Kit; качество перевода может уступать облачным переводчикам.

## Ограничения MVP

Сайт является сторонним ресурсом, и его структура/доступность может меняться. Некоторые главы могут быть недоступны серверному HTML-парсеру из-за клиентского JavaScript или защит от автоматического доступа. Приложение не обходит платный доступ, CAPTCHA, авторизацию и другие ограничения сайта. Статус успешной сборки APK и поведение на реальном устройстве следует проверить отдельно.

Исходные тексты принадлежат их правообладателям. Проект не связан с администрацией mtlnovel.me.
